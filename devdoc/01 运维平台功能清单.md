## 二、功能模块清单

### 模块一：合同管理（核心）

| 功能点 | 详细说明 | 关键字段 |
|--------|----------|----------|
| **主合同管理** | 规定承接公司（总包方）与甲方签订的总体运维合同，关联服务单位和乙方管理人 | 合同编号、甲方名称、总包方、乙方管理人、服务单位、合同金额、签订日期、生效日期、到期日期、付款方式、合同状态、附件 |
| **分包合同管理** | 总包方与各个运维软硬件公司签订的分包合同，关联服务单位 | 关联主合同、分包商名称、服务单位、分包金额、服务范围、服务等级(SLA)、合同类型(软件/硬件/机房) |
| **合同台账** | 所有合同的统一视图，支持多维度筛选 | 合同编号、项目名称、金额区间、到期预警、状态筛选 |
| **合同附件管理** | PDF盖章文件上传、预览、版本管理 | 支持Word电子版+PDF盖章版双上传、下载权限控制 |
| **合同附件开关** | 控制运维单位是否可查看合同附件 | 主合同/分包合同独立开关，关闭后运维单位不可见 |
| **项目经理分配** | 为主合同/分包合同分配项目经理 | 多选项目经理，项目经理只看自己负责的合同 |
| **合同金额权限** | 按角色控制合同金额可见性 | 运维单位/访客隐藏金额显示为*** |
| **合同到期预警** | 自动计算合同剩余时间，提前N天提醒 | 30天/60天/90天预警阈值配置 |
| **合同费用统计** | 按年度/项目/分包商汇总合同金额 | 可视化图表展示 |
| **合同续签管理** | 到期合同发起续签流程 | 续签记录、历史版本追溯 |
